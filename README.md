# Nexus Agency OS

A modern SaaS-based agency management platform built with React and Supabase to centralize client, project, and recruitment workflows into a unified dashboard.

## 🌐 Live Demo

https://nexus-os-dashboard-seven.vercel.app/

## 🚀 Features

- Secure authentication with Supabase Auth
- Role-based access control (Admin / Client / Developer)
- Protected routes based on user permissions
- Client management
- Project lifecycle management
- Recruitment workflow
- Responsive dashboard interface
- Scalable feature-based architecture

---

## 🛠 Tech Stack

### Frontend

- React
- JavaScript
- React Router
- TanStack React Query
- Context API
- useReducer

### Backend

- Supabase
- PostgreSQL
- Supabase Authentication
- Row Level Security (RLS)

---

## ✨ Project Highlights

- Designed a scalable feature-based architecture for long-term maintainability.
- Implemented secure authentication and role-based authorization using Supabase.
- Managed server state with TanStack React Query, including caching and background synchronization.
- Managed complex client-side state using Context API and useReducer.
- Leveraged Supabase as a Backend-as-a-Service for database, authentication, and secure data access.

## 📦 Installation

```bash
git clone https://github.com/Ali-jalili/Nexus-Os-Dashboard.git

cd Nexus-Os-Dashboard

npm install

npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file in the project root and add:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
